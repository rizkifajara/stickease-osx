# StickEase

StickEase is a lightweight, floating sticky notes application for macOS that helps you keep important notes visible on your screen while you work.

## Features

- Create multiple floating sticky notes
- Notes stay on top of other windows
- Edit and view modes for each note
- Show/hide individual notes

## System Requirements

- macOS 13.5 or later
- Apple Silicon or Intel Mac

## Installation

1. Download the latest release from the [releases page](https://github.com/rizkifajara/stickease-osx/releases)
2. Extract and move StickEase.app to your Applications folder
3. Launch StickEase

### Creating Notes
- Click the menu bar icon and select "New Note"
- Use ⌘N keyboard shortcut
- Click the "+" button on any existing note

### Managing Notes
- Click the pencil icon to edit a note
- Use the eye icon to switch to view mode
- Toggle visibility using the switch
- All notes can be shown using "Show All Notes" from the menu bar

### Customization
- Notes can be resized
- Drag notes anywhere on your screen
- Notes automatically save as you type

## Development

The project is built using:
- SwiftUI for the user interface
- AppKit integration for window management
- MVVM architecture pattern

To build from source:
1. Clone the repository
2. Open StickEase.xcodeproj in Xcode
3. Build and run the project
